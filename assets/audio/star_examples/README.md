# Star pickup sound examples

Ten short, single-hit sound effects generated with ElevenLabs Sound Effects v2 for repeated star pickups. Audition files are not wired into gameplay.

| File | Concept |
| --- | --- |
| `star_01.mp3` | Rounded wooden bead tap |
| `star_02.mp3` | Muted kalimba pluck |
| `star_03.mp3` | Felt mallet marimba tap |
| `star_04.mp3` | Cushioned bubble pop |
| `star_05.mp3` | Delicate cork click |
| `star_06.mp3` | Soft bamboo tap |
| `star_07.mp3` | Warm analog synth bloop |
| `star_08.mp3` | Muted ceramic pebble tap |
| `star_09.mp3` | Damped pizzicato string |
| `star_10.mp3` | Padded xylophone knock |

Each prompt requested one restrained sound with a short decay. The model was set to 0.5 seconds, prompt influence 0.5, and no loop. The original generations varied greatly in volume. These audition files have been balanced to about -17.5 dBFS mean with rounded peaks and a short end fade. The original quiet takes and the louder balanced uploads are both labeled in the [ElevenLabs flow](https://elevenlabs.io/app/flows/qr5tgHGaWYeSt6i1r9sp).

`repeat_previews/` plays each balanced cue eight times with a short gap to make repetition fatigue easier to judge. The standalone `star_XX.mp3` files are the actual candidates for the game.
