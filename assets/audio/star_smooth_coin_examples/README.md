# Smooth coin pickup examples

Ten additional ElevenLabs Sound Effects v2 takes based on the rounded rising ping of `star_coin_examples/coin_01.mp3`, the closest match from the previous batch. All ten share one prompt so the comparison focuses on small variations within that sound rather than different sound types.

The source takes were generated at 0.5 seconds with prompt influence 0.7 and no loop. The standalone `smooth_coin_01.mp3` through `smooth_coin_10.mp3` files were balanced to about -16.5 dBFS mean, given a 2.5 ms onset fade, a 10 ms end fade, and a gentle high-frequency rolloff. `repeat_previews/` plays each cue eight times, 280 ms apart, to check how it feels in a rapid star sequence.

[Open the ElevenLabs flow](https://elevenlabs.io/app/flows/XvXXwxqQ2RtObeRSRsZP) for the original generation node and ten labeled balanced uploads. These are audition files; the game has not selected a new pickup sound yet.
