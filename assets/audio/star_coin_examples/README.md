# Arcade coin-style star pickup examples

Ten original, short coin pickup sounds generated with ElevenLabs Sound Effects v2 after the Subway Surfers direction was given. These are audition candidates and are not yet used by the game.

| File | Character |
| --- | --- |
| `coin_01.mp3` | Ascending metallic ping |
| `coin_02.mp3` | Digital pitch flick |
| `coin_03.mp3` | Glassy coin pling |
| `coin_04.mp3` | Retro synth bell |
| `coin_05.mp3` | Rounded ka-ching |
| `coin_06.mp3` | Gold coin ping |
| `coin_07.mp3` | Bell sparkle |
| `coin_08.mp3` | Rising synth blip |
| `coin_09.mp3` | Reward plink |
| `coin_10.mp3` | Runner-game two-note ping |

The source generation used 0.5 seconds, prompt influence 0.65, and no loop. The standalone files were balanced to about -17 dBFS mean with rounded peaks and a short end fade. `repeat_previews/` plays each candidate eight times with pickups 280 ms apart. The [ElevenLabs flow](https://elevenlabs.io/app/flows/s3Ln02GnJC2LR4pFi1CB) contains the labeled source takes and balanced uploads.
